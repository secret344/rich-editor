# 📝 Rich Text Editor

A modern rich text editor package based on Tiptap 3.x.

## 📦 Installation

```bash
npm install @my-editor/rich-text-editor
# or
yarn add @my-editor/rich-text-editor
# or
pnpm add @my-editor/rich-text-editor
```

## Features

1. suggestion
2. styles
3. Menu needs to be passed as parameters, modify the rendering component to a common component, and render different menu forms according to different configurations.
