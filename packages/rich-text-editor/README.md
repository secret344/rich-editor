# 📝 Rich Text Editor

[中文文档](./README.zh-cn.md)

A modern rich text editor package based on Tiptap 3.x, featuring independent extension architecture, focusing on memory safety, component-based design, and excellent developer experience.

## ✨ Core Features

- **🎯 Modern Architecture**: Based on Tiptap 3.x with independent extension architecture, abandoning StarterKit
- **🔧 TypeScript**: Complete type definitions for excellent developer experience
- **🌐 Framework Agnostic**: Pure JavaScript implementation, integrates with any project
- **🛡️ Memory Safety**: Unified EventManager with comprehensive resource cleanup mechanisms
- **🧩 DOM Component System**: Unified DOM operation tools with componentized design for buttons/dialogs/pickers
- **🎨 Professional Positioning**: Integrated floating-ui for intelligent popup positioning system
- **📦 Bundle Size Optimization**: Independent extension architecture reduces bundle size by ~11% with better Tree-shaking
- **📱 Responsive Design**: Adapts to various screen sizes and devices

## 📦 Installation

```bash
npm install @my-editor/rich-text-editor
# or
yarn add @my-editor/rich-text-editor
# or
pnpm add @my-editor/rich-text-editor
```
