# 🚀 Modern Rich Text Editor

[中文文档](./README.zh-cn.md)

A modern rich text editor project based on Tiptap 3.x.

## 📦 Project Features

### 🎯 Core Features
- **Rich Text Editing**: Support text formatting, paragraph styles, lists and other basic editing features

- **Extensible Architecture**: Based on Tiptap's plugin system, supports custom extensions and feature modules

- **Framework Agnostic**: Pure JavaScript implementation, can be used in any frontend framework



### 🛠️ Technical Features
- **TypeScript Support**: Complete type definitions and type safety

- **Modular Design**: Uses monorepo architecture with clear code organization for easy maintenance

- **Modern Build**: Fast build and hot reload based on Vite

- **Style Customization**: Supports Tailwind CSS for easy theme customization and style extension

### 📦 Package Structure
- **@my-editor/rich-text-editor**: Core rich text editor package, framework agnostic

- **Example Application**: Complete usage examples and feature demonstrations
