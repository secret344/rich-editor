# 🚀 现代化富文本编辑器

基于 Tiptap 3.x 的现代化富文本编辑器项目。

## 📦 项目功能

### 🎯 核心功能
- **富文本编辑**: 支持文本格式化、段落样式、列表等基础编辑功能

- **扩展性架构**: 基于 Tiptap 的插件系统，支持自定义扩展和功能模块

- **无框架依赖**: 纯 JavaScript 实现，可在任何前端框架中使用



### 🛠️ 技术特性
- **TypeScript 支持**: 完整的类型定义和类型安全

- **模块化设计**: 采用 monorepo 架构，代码组织清晰，便于维护

- **现代化构建**: 基于 Vite 的快速构建和热更新

- **样式定制**: 支持 Tailwind CSS，易于主题定制和样式扩展

### 📦 包结构
- **@my-editor/rich-text-editor**: 核心富文本编辑器包，无框架依赖

- **示例应用**: 完整的使用示例和功能演示
